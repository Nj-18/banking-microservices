# Banking Application

A production-grade banking application built using Spring Boot.

## Features

- Customer Management
- Bank Account Management
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Global Exception Handling
- DTO & Mapper Pattern
- Spring Data JPA
- MySQL

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok
